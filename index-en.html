My Previous Projects

Remotely Controlled Vehicle

I designed in Fusion 360 and then 3D printed a remotely controlled vehicle. It moves on toothed belts printed from flexible thermoplastic polyurethane. The vehicle connects to WiFi and provides a website where you can see a camera preview and control it. Communication between the web interface and the vehicle is done using Web Sockets, and the vehicle software is written in Python. It runs on a Raspberry Pi microcomputer and a self-designed electronic circuit that provides power and motor control.

Project description on Forbot.pl

Line Following Robot

Robot using reflective sensors to detect lines and a proportional-differential controller to control motors. I used an ESP32 microcontroller and wrote the software in MicroPython.
